# Godot renderer: Compatibility

Date: 2026-11-15. Owner: Jess. Canonical: docs/discussion-outputs/godot-primer.md

- The project uses Godot's Compatibility renderer (lightest, runs on older and work GPUs, the only one that can
  export to the web).
- Forward+ and Mobile are not used; a 2D pixel tactics game needs none of their features.
