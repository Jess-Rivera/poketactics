# Currencies and home

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/game-design.md

- Silver: in-run currency for shops and healing; resets to 0 each run.
- PokeCoins: persistent meta currency, earned as an end-of-run reward based on how far and how well the run went,
  spent at home on meta progression.
- Home is where the main menu options live. It starts as a plain menu; in M4 it becomes a walkable town in the
  style of Pokemon Mystery Dungeon, with each option a physical location.
