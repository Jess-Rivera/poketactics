# Fainting and recovery

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/game-design.md

- A fainted Pokemon can be revived during the run (heal nodes, Revive items); a revive cancels its recovery.
- A Pokemon still fainted when the run ends stays in the boxes but is Recovering: it cannot be used in the
  following run(s), for longer the deeper into the run it fainted.
- Shop items reduce recovery time.
