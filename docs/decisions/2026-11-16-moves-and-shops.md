# Moves: level-up automatic, shops sell the rest

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/game-design.md

- Level-up moves are learned automatically as a Pokemon levels.
- Shops sell machine, tutor and egg moves, gated by level: a move appears only if a Pokemon in the roster can
  learn it at its current level. Levels (carried between runs) therefore shape what shops offer.
