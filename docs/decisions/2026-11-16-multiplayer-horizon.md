# Multiplayer is the horizon

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/game-design.md

- Horizon goal: multiplayer, both cooperative and competitive.
- Early step: local hotseat versus right after M1 (M1b). Both players free-pick 6 units from the pack at one set
  level; no save file needed.
- Battle rules stay deterministic, seeded and headless so later lockstep play and replays stay possible.
- No online code (accounts, servers, cloud) until Jess says so.
