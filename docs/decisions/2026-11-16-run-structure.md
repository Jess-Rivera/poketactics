# Run structure: one region on a branching map

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/game-design.md

- The player is a trainer. A run is one attempt at a region: 8 Gym Leaders, then the 4 Elite Four, then the option
  to fight ONE of the region's legendaries for a chance to catch it.
- Between battles is the Run Map, branching like Slay the Spire: regular encounter nodes, elite nodes, shop
  nodes, heal nodes and checkpoint nodes.
- Target length: about 6 hours or more per run.
- Long-term structure follows the fork's FULL-GAME-STRUCT ideas minus loops and loop checkpoints (the map replaces
  them). Its endgame parts are parked (2026-11-16-first-build-scope).
