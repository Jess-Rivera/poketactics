# Terrain-type bonus

Date: 2026-11-16. Owner: Jess. Canonical: docs/discussion-outputs/battle-design.md

- Each of the 18 types has a terrain (tile, tile set or prop), for example tall grass for Grass.
- A unit standing on its own type's terrain deals 1.2x with attacks of that type.
- The bonus is lost when the tile changes (burnt grass, frozen water).
